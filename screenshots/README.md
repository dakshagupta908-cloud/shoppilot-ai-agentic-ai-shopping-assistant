# Application screenshots

No application screenshots are currently included. Capture the actual running application; do not use mockups or generated images as proof of functionality.

Save approved captures in this directory using these names:

1. `home.png` — home page and primary navigation.
2. `assistant.png` — AI shopping assistant with a user prompt and response.
3. `recommendations.png` — catalogue-backed product recommendations and explanations.
4. `comparison.png` — two or three real catalogue products in the comparison view.
5. `cart.png` — populated guest cart with quantities and totals.
6. `checkout.png` — checkout summary showing the disclosed Sandbox conversion.
7. `order-confirmation.png` — only after a genuine Sandbox buyer approval and backend-verified `COMPLETED` capture.

Before sharing, remove or obscure personal account details and any credentials, tokens, buyer email addresses, or other sensitive information. Never create an order-confirmation image from mocked data or an unverified order.
